# Fonts

The four typefaces GDD §16.6 names, as Latin-subset WOFF2 files from Google Fonts (downloaded 2026-11-17).
All are under the SIL Open Font License 1.1; each family's licence ships beside it.

| File | Family | Use | Licence |
|---|---|---|---|
| `eb-garamond-var.woff2`, `eb-garamond-italic-var.woff2` | EB Garamond (variable weight) | dialogue, story, menus, headings | `OFL-ebgaramond.txt` |
| `inter-var.woff2` | Inter (variable weight) | HUD, numbers, buttons, small labels | `OFL-inter.txt` |
| `caveat-var.woff2` | Caveat (variable weight) | handwriting: the Fellowship form, letters | `OFL-caveat.txt` |
| `old-standard-tt-400.woff2`, `-700.woff2`, `-400-italic.woff2` | Old Standard TT | the Lantern and other newsprint | `OFL-oldstandardtt.txt` |

The Latin subset covers U+0000–00FF, general punctuation (U+2000–206F), ↑ ↓ and €. Other glyphs (→, ←, ✿)
fall back to the next font in each stack.
